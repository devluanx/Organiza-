# Organiza +


## Descrição
O Organiza+ é uma aplicação web de gerenciamento de tarefas desenvolvida com HTML, CSS e JavaScript.
A aplicação permite que o usuário cadastre suas tarefas, acompanhe as atividades adicionadas e marque tarefas como concluídas.
As informações são armazenadas no navegador utilizando `localStorage`, permitindo que as tarefas continuem disponíveis mesmo depois de atualizar ou fechar a página.


## Objetivo
O objetivo foi criar uma ferramenta que ajuda a se organizar com suas tarefas, sem ter que usar papéis e etc.
Além disso, o projeto foi desenvolvido para praticar conceitos importantes de programação e desenvolvimeto web.

Durante o desenvolvimento foram aplicados:
- DOM;
- Eventos JS;
- Arrays e objetos;
- Funções;
- Estruturas condicionais;
- Validação de dados;
- `LocalStorage`;
- Criação dinâmica de elementos HTML;
- Organização do código;
- Responsividade com o CSS.

## Tecnologias Utilizadas
- HTML = estrutura da página;
- CSS = estilização da página
- JavaScript = lógicas e funcionalidades;
- DOM = manipulação dos elementos;
- JSON = armazenamentos dos dados;
- `LocalStorage` = Salvamento das tarefas.


## Funcionalidades
- Adicionar tarefas;
- Registrar título de cada tarefa;
- Marcar tarefas como concluídas;
- Alterar o estado das tarefas;
- Excluir tarefas;
- Recuperar tarefas ao fechar e abrir a aplicação;


## Como Executar
1. Baixe ou clone o projeto;
2. Entre na pasta do projeto;
3. Abra o arquivo `index.html` no navegador
4. Agora se organize com o Organiza +
